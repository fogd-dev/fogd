### Broader Future Scope (Non-Blocking / M8+)

- **Post-restore divergence vs. idempotent retry receipt:** Once `transfer_state` reaches `status = 'complete'`, re-importing the identical snapshot digest returns `{ alreadyRestored: true }` without re-checking whether new post-restore rows have been added to `messages` or `attachments`. In [`transfer()`](file:///Users/sgtpooki/code/sgtpooki/fogd/scripts/guestbook-transfer.mjs#L46-L47), the immediate post-import `/__fogd/export` comparison catches any post-restore divergence, so this is completely safe for the M7b maintenance script.
- **Unreferenced R2 orphan cleanup & slot retirement:** Orphan R2 objects from interrupted live uploads (prior to SQL insert) are intentionally excluded by the logical export profile, and reserved R2 bucket prefixes remain bound for the life of the app slot until M8 backup/retirement semantics.
